# Эмулятор оболочки UNIX-подобной ОС (Вариант №5)

## Общее описание
CLI/GUI эмулятор командной строки с поддержкой виртуальной 
файловой системы (VFS) на основе JSON. Реализован на Python 
с использованием tkinter. Поддерживает конфигурацию через 
аргументы командной строки и выполнение стартовых скриптов.

## Функции и настройки
| Параметр | Описание |
|----------|----------|
| `-vfs <path>` | Путь к JSON-файлу виртуальной ФС |
| `-script <path>` | Путь к стартовому скрипту команд |

### Поддерживаемые команды
- `ls [path]`, `cd [path]`, `mkdir <name>`
- `whoami`, `cal`, `who`, `exit`
